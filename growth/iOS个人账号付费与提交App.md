# iOS 实操：个人付费注册开发者账号，提交第一个 App

[iOS 出海上架](iOS出海上架与开发者账号.md) 讲的是选什么身份、钱怎么收、以后怎么换成公司。这篇只讲动手的部分：**用个人身份把年费交了，再把第一个 App 送进审核**，照着做就行。

规则按 2026 年 11 月 Apple 官方帮助页面整理，第三方经验会单独标出来。动手前请再核对一遍。

---

## 一、开始前先确认

| 项目 | 要求 |
| --- | --- |
| 身份 | 个人账号用**法定姓名**，不能用别名、昵称或公司名。这个名字会作为卖家名显示在商店里（见 [iOS 出海上架](iOS出海上架与开发者账号.md) 第二节） |
| Apple 账户 | 开启双重认证；**从没注册过开发者**的账户最稳。之前在网页上申请过、没付成功的账户，有人反馈在 App 里注册会卡住 |
| 年龄 | 达到所在地区的法定成年年龄 |
| 设备 | 大陆身份：iPhone 或 iPad，登录 iCloud，打开锁屏密码、Face ID 或 Touch ID，装好最新版 Apple Developer App |
| 开发用的 Mac | 2026 年 4 月 28 日起，上传的构建版本必须用 **Xcode 26** 以上、iOS 26 SDK 编译。旧 Mac 装不了 Xcode 26 的，要先解决机器问题 |
| 已有账号 | 以前用别的身份注册过、账号还在的，**优先续费旧账号**，不要再开一个。同一个人名下的账号会被当成关联账号，小型企业计划的收入要合并计算 |

---

## 二、付费注册

### 1. 大陆身份：在 Apple Developer App 里注册，¥688

大陆开发者走网页注册一般通不过，要用 App：

1. App Store 搜索下载 **Apple Developer**，打开「帐户」标签页，登录 Apple 账户
2. 点「现在注册」，按提示**验证身份**：填名字、姓氏、身份证号、手机号，然后拍一张自拍做人脸核验。点「继续」以后，填过的内容就改不了了
3. 选择**个人**身份
4. 确认会员订阅，点「以每年 ¥688 订阅」
5. 付款走 App Store 的支付方式，也就是**这个 Apple 账户绑定的支付宝、微信支付或银行卡**。**不能用 Apple 账户余额**
6. 付款成功会收到确认邮件。多数人几小时到两天内审核完，会收到欢迎邮件

**付款的几个细节：**

- 这是**按年自动续订的订阅**，和 App 里的其他订阅一样，不取消就每年自动扣 ¥688。在「设置」→ 你的名字 →「订阅」里可以查看和取消，最晚在续订日前一天取消
- 想用别的卡付，先把卡绑到**当前登录的这个 Apple 账户**上，再回来付款
- 收据会发到 Apple 账户的邮箱，可以拿去记账或报销
- 付款失败、提示「支付授权失败」的，一般是身份没验证通过，或者支付方式有问题。换一种支付方式再试；还不行，打 Apple 开发者支持（中国大陆 400-670-1855）。**不要换新账户反复提交**

### 2. 非大陆身份（比如香港）：在网页上注册

1. 打开 [developer.apple.com/programs/enroll](https://developer.apple.com/programs/enroll/)，用 Apple 账户登录，选个人身份，填法定姓名和地址
2. 在 Apple Store 在线商店结账，价格按当地货币显示（美国是 $99）
3. **个人注册用信用卡付款的，必须用你本人名下的卡**，否则注册会被延迟
4. 没收到确认邮件的，24 小时后带着 **Enrollment ID** 去联系开发者支持

也可以用 Apple Developer App 注册，同样是按年自动续订。

### 3. 续费和过期

- 会员到期前 30 天，开发者网站会提示续费。App 里注册的会自动扣款；网页注册的可以在账户页面打开自动续订
- **过期了会怎样：** App 会从 App Store 下架，TestFlight 也停掉。已经装了的用户一般还能继续用，但收不到更新，新用户也下载不了。续费以后可以重新上架，App 记录和评分都还在
- 身份信息变了（地址、居留身份等），见 [iOS 出海上架](iOS出海上架与开发者账号.md) 第三节，去联系开发者支持更新

## 三、提交前的准备

### 1. 先签协议

登录 [App Store Connect](https://appstoreconnect.apple.com) →「商务」：

- **免费 App**：接受免费 App 协议就能提交
- **收费、有内购或订阅**：还要签**付费 App 协议**，并且填完 W-8BEN 税表和银行信息，三样都填完才生效。填法见 [iOS 出海上架](iOS出海上架与开发者账号.md) 第五节

签完以后，顺手去申请**小型企业计划**，申请后抽成从 30% 降到 15%，批准之前的收入不追溯。

### 2. 在 Xcode 里配好工程

1. Xcode →「Settings」→「Accounts」，登录开发者账号
2. Target →「Signing & Capabilities」：Team 选你的个人团队，勾选 **Automatically manage signing**
3. **Bundle Identifier** 用倒写的域名，比如 `com.craftsail.app`。**上架以后就不能改**，先想好
4. 版本号（Version）从 `1.0.0` 开始；每次上传，构建号（Build）都要比上一次大
5. 只用系统自带的 HTTPS 加密的，在 Info.plist 里加 `ITSAppUsesNonExemptEncryption = NO`，以后上传就不用每次回答出口合规问题

### 3. 审核最常卡的几条，开发阶段就做好

| 要求 | 怎么做 |
| --- | --- |
| **支持注册账号，就要支持删除账号**（审核指南 5.1.1(v)） | App 里要有删除账号的入口，不能只给一个客服邮箱 |
| **用了 Google、Facebook 这类第三方登录**（4.8） | 要再提供一个注重隐私的登录方式，最省事的是加 Sign in with Apple |
| **卖数字内容、订阅**（3.1.1） | 必须走 Apple 内购。App 里不能直接接 Stripe 收款（美国区的外部付款链接除外，见 [出海收款](出海收款.md) 第十节） |
| **功能完整，不闪退**（2.1） | 不能有「敬请期待」的空页面、占位文字、死链接。在真机上从安装开始完整走一遍 |
| **不能是网页套壳、模板 App**（4.2 / 4.3） | 要有原生的功能和体验。只是把网站包一层的，很容易被拒 |
| **隐私权限要说明用途** | Info.plist 里每个权限（相机、相册、定位等）都要写清楚**具体用来做什么**，用英文写 |
| **第三方 SDK 的隐私清单** | 统计、广告、崩溃上报这类 SDK 升级到带 `PrivacyInfo.xcprivacy` 的版本 |

## 四、在 App Store Connect 里建 App

「App」→「+」→「新建 App」：

| 字段 | 填法 |
| --- | --- |
| 平台 | iOS |
| 名称 | 商店里显示的名字，最多 30 个字符，**全商店不能重名**。被别人占了就换一个，或者加个后缀 |
| 主要语言 | 只做海外的选 English (U.S.) |
| 套装 ID | 选 Xcode 里那个 Bundle ID。下拉框里没有的，去开发者网站「Identifiers」里先建一个 |
| SKU | 你自己用的编号，用户看不到，比如 `craftsail-ios-001` |
| 用户访问权限 | 个人账号选「完全访问权限」 |

## 五、填商店资料

### 1. App 信息（所有版本共用）

- **副标题**：最多 30 个字符，一句话说清楚做什么
- **类别**：选一个主类别，可以再选一个次类别
- **年龄分级**：按问卷如实填。2026 年 1 月 31 日起要回答**新版的分级问题**（分级档位变成 4+、9+、13+、16+、18+），不答完提交不了
- **内容版权**：用了第三方内容的，要确认你有权使用

### 2. 价格与销售范围

- 免费就选 0 档；收费的选一个价格档位，Apple 会自动换算成各国价格
- **App 销售范围**：只做海外的，**取消勾选中国大陆**，这样就不用填备案号
- 要上欧盟区，先在「商务」里完成 **DSA 交易商声明**（个人账号的地址、电话、邮箱会公开显示）。不想公开就先不勾欧盟

### 3. App 隐私

- **隐私政策网址**：必填，放在你自己的网站上，用英文写
- **数据收集问卷**：如实填收集了哪些数据、是否和用户身份关联、是否用于追踪。第三方 SDK 收集的数据也要算进去。填完要点「发布」

### 4. 版本页面（每个版本都要填）

| 项目 | 要求 |
| --- | --- |
| **截图** | iPhone 至少传一张 **6.1 英寸（带灵动岛的中尺寸屏幕）** 的截图：竖屏 1179 × 2556 或 1206 × 2622 像素。支持 iPad 的，还要传 13 英寸 iPad 截图：2064 × 2752 或 2048 × 2732。每个尺寸最多 10 张，jpg 或 png。界面在各尺寸上一致的，只传最高的必需分辨率，App Store Connect 会自动缩小给其他尺寸用 |
| 宣传文本 | 最多 170 个字符，以后改不用重新审核，适合放活动信息 |
| 描述 | 最多 4000 个字符。前三行最重要，用户不点「更多」只能看到这些 |
| 关键词 | 最多 100 个字符，用英文逗号隔开，逗号后面不要加空格；不要重复写名称里已有的词，也不要写竞品的名字 |
| 技术支持网址 | 必填，一个能联系到你的页面 |
| 营销网址 | 选填，放产品官网 |
| 版权 | 比如 `2026 Zhang San`，个人账号写你的名字 |

截图建议前两张就讲清楚核心功能，加一句大字说明，而不是只放原始界面。

## 六、上传构建版本，先自己测

1. Xcode 顶部的运行目标选 **Any iOS Device (arm64)**
2. 菜单 **Product → Archive**，打包完会打开 Organizer
3. 点 **Distribute App** → **App Store Connect** → Upload，一路默认
4. 上传后 App Store Connect 要处理 10–30 分钟，处理完会收到邮件。有问题（比如缺权限说明）也会发邮件告诉你
5. **TestFlight** 标签页：
   - 自己和团队成员是**内部测试**，不用审核，装上就能测
   - 邀请外部用户（最多 1 万人）是**外部测试**，第一个版本要过一次 Beta 审核，一般一天以内
6. 在真机上至少完整走一遍：安装 → 注册 / 登录 → 核心功能 → 付费（用沙盒账号）→ 删除账号

## 七、提交审核

1. 回到版本页面，在「构建版本」里选刚上传的那个
2. **App 审核信息**：
   - 需要登录才能用的，**一定要给测试账号和密码**，并且确认账号能用。这是被拒最常见的原因之一
   - 「备注」里用英文写清楚：App 是做什么的、核心功能在哪、有没有需要特殊硬件或地区才能用的功能
   - 留一个能联系到你的电话和邮箱
3. 有内购或订阅的：商品先在「App 内购买项目」或「订阅」里建好，填好截图和说明，**和这个版本一起提交**。第一个内购商品必须跟新版本一起审
4. **版本发布方式**：
   - 「手动发布」：审核通过后你自己点发布，适合要配合宣传的时候
   - 「自动发布」：通过后马上上架
   - 「分阶段发布」：自动更新的用户 7 天内分批拿到新版本，只对更新有效，第一个版本用不上
5. 点「添加以供审核」→「提交以供审核」

**审核时间**：多数在 24–48 小时内出结果，状态会从「正在等待审核」变成「正在审核」，再变成「可供销售」或「被拒绝」。

---

## 八、被拒了怎么办

- 去 App Store Connect 的 **App 审核**（以前叫 Resolution Center）看具体原因，里面会写违反了审核指南的哪一条
- **改了就重新提交**：上传新的构建版本（构建号加 1），或者只改商店资料，然后重新提交
- **觉得审核员误会了**：直接在里面用英文回复解释，附上截图或录屏，不用改代码。说清楚事实就行，不用跟审核员争
- 解释不通的，可以向 App 审核委员会**申诉**
- 第一次上架被拒一两次很常见。按指南条款逐条改，比反复猜要快

---

## 九、上架后

- 上架以后用 App Store 链接 `https://apps.apple.com/app/id<你的 App ID>` 分享，App ID 在「App 信息」里
- **每个月**看「付款和财务报告」，核对到账（见 [iOS 出海上架](iOS出海上架与开发者账号.md) 第五节）
- 每次更新都要重新审核，版本号要加
- 回复用户评论，在「评分与评论」里操作
- 想看下载量和转化：「App 分析」可以看展示次数 → 产品页浏览 → 下载的漏斗

## 十、清单

**注册**

- [ ] 准备好开过双重认证、没注册过开发者的 Apple 账户
- [ ] 大陆身份：在 Apple Developer App 里用身份证验证，用支付宝 / 微信 / 银行卡付 ¥688
- [ ] 非大陆身份：网页注册，用**本人名下的信用卡**付款
- [ ] 收到欢迎邮件，确认会员已生效
- [ ] 想好要不要自动续订，记下续订日期

**上架**

- [ ] 签协议；收费的再填税表和银行信息，申请小型企业计划
- [ ] 用 Xcode 26 以上编译，Bundle ID 定好
- [ ] 删除账号、第三方登录、内购、权限说明这几条自查过
- [ ] 隐私政策和技术支持页面上线
- [ ] 建 App，填名称、类别、年龄分级、价格，**去掉中国大陆**
- [ ] 欧盟区上不上，上就先做 DSA 声明
- [ ] 6.1 英寸 iPhone 截图（支持 iPad 的再加 13 英寸 iPad）
- [ ] 描述、关键词、App 隐私问卷
- [ ] Archive 上传，TestFlight 真机完整测一遍
- [ ] 填测试账号和审核备注，提交审核
