# 流量公式与阶段权重

新站只做 SEO，做不起来。Ahrefs 2017 年跟踪了 200 万个新页面，一年内能在至少一个词上进前十的只有 5.7%，而且大多是高权重域名上的页面；更新后的数据（第三方转述）只剩 1.74% 左右。新域名、没外链、没人提起，SEO 要很久才转得动。

但这不是说 SEO 没用，而是**在不同阶段，不同渠道的权重不一样**。刚起步时，靠的是创始人自己去找人、社区、发布；起量以后，SEO、口碑、集成这些会复利的东西才接手；再往后，付费、合作、老客户扩张才划算。

这篇想把这件事写成一个公式：

```text
流量 = f(SEO, 社区, KOL, 发布, 外联, 广告, 口碑, ……; 阶段)
```

每个渠道是一个自变量，有自己的权重；权重随阶段变化。下面先给公式的骨架和依据，再列自变量清单、各阶段的权重表、怎么用自己的数据把权重估出来，最后是每个方向的研究路线。这篇是一份研究地图，每个方向后面还要单独写。

## 一、几条已经被反复验证的规律

建模之前，先把有依据的规律摆出来。公式的形状要符合这些规律，不然就是在拟合噪声。

### 1. 分发服从幂律：大部分增长来自一个渠道

Peter Thiel 的说法：大多数公司一个渠道都跑不通；跑通一个，就是好生意；试了好几个、一个都没跑透，就完了。

Brian Balfour（前 HubSpot 增长 VP、Reforge 创始人）给了一个更具体的数：**在任一时刻，具备产品-渠道匹配的公司，70% 以上的增长来自一个渠道**。同时在多个渠道上跑通的公司很少，LinkedIn 是例子（病毒传播、UGC SEO、销售）。

Lenny Rachitsky 调研了几十个大型消费类产品的前 1,000 个用户，结论相同：多数只靠一种方法，最多不超过三种。

《Traction》（DuckDuckGo 创始人 Gabriel Weinberg 写的）列了 19 个渠道，用 Bullseye 框架筛：每个渠道都想一个便宜的试法，挑三个最有希望的去测，最后集中到一个核心渠道。

**对公式的含义：** 权重向量很稀疏。某个阶段里，通常一个渠道的权重远大于其他所有渠道之和。模型里不该给每个渠道都分一点。

### 2. 渠道会衰减

Andrew Chen（a16z 合伙人，前 Uber 增长负责人）的「垃圾点击率定律」：**所有营销手段最终都会变成很差的点击率**。1994 年 HotWired 的横幅广告点击率是 78%，2011 年 Facebook 广告是 0.05%。原因是新鲜感会过去、先发优势不会一直在、规模越大用户质量越低。他说一个渠道被跑通后，竞争对手跟进，通常 6–12 个月就会明显下滑。

**对公式的含义：** 同一个渠道的效率会随日历时间下降，和你自己处在哪个阶段无关。权重 = 阶段系数 × 渠道当期效率，后者要单独随时间衰减。

### 3. 早期靠外部推力，后期靠内生拉力

这是 Bass 扩散模型（1969）的核心。它把新采用者分成两部分：

- 受外部影响而来的（创新者）：广告、媒体、搜索、发布，系数 p
- 受已有用户影响而来的（模仿者）：口碑、看到别人在用，系数 q

```text
新增(t) = [ p + q × N(t)/M ] × ( M − N(t) )

N(t)：累计用户   M：这个市场最多能有多少用户
```

Sultan、Farley、Lehmann 1990 年对 213 组参数做了元分析，平均 p ≈ 0.03，q ≈ 0.38（按年），离散度很大。数值来自耐用品和传统行业，不能直接套到网站上，但形状有参考价值。

从公式能推出：任一时刻，新增里来自外部推力的比例是

```text
外部占比 = p ÷ ( p + q × F )      F = N/M，已占领的市场比例
```

用平均值 p = 0.03、q = 0.38 算：

| 已占领市场 F | 外部推力占新增的比例 | 口碑占新增的比例 |
| --- | --- | --- |
| 0% | 100% | 0% |
| 1% | 89% | 11% |
| 5% | 61% | 39% |
| 10% | 44% | 56% |
| 25% | 24% | 76% |
| 50% | 14% | 86% |

这张表就是「阶段权重会变」的数学来源：**刚开始口碑的权重是零**，因为没有用户可以带人；用户积累起来以后，口碑项按 N 成比例增长，外部渠道的相对权重自然下降。

注意这里的 M 是你那个细分市场的上限，不是全世界。做一个给 Figma 设计师用的工具，M 可能只有几万。细分得越窄，F 涨得越快，口碑接手得越早。这也是 Andrew Chen《The Cold Start Problem》里说的「原子网络」：先在一个足够小的圈子里做到密度，再一个圈一个圈地复制。

### 4. 早期的方法都不能规模化，这正是它们有用的原因

Paul Graham 的《Do Things That Don't Scale》：早期用户要一个个去找、去拉。

Lenny 的两组调研：

- **消费类产品前 1,000 用户**，7 种方法覆盖了几乎所有案例，最常见的都是直接去找用户：线上线下去用户在的地方、找朋友和同事、找有针对性的陌生人。其他是邀请制 / 等候名单、找 KOL、媒体、社区
- **B2B 前 10 个客户**，第一来源是创始人的人脉（前同事、朋友），第二是冷外联。他把早期渠道描述成以创始人为圆心、信任度逐层递减的同心圆。PR 偶尔有用，多数时候没用

**对公式的含义：** 冷启动阶段最大的自变量是「创始人的时间」，而不是任何一个平台。

### 5. 独立开发者和小 SaaS 的数据

- **MicroConf 2024 独立 SaaS 调查**（约 700 家）：创始人认为影响最大的营销是 SEO 和口碑。投广告的人里，57% 要 7 个月以上才回本，或者根本说不清有没有用。65% 的公司只有 1–10 个付费用户
- **IndieLaunches 分析了 326 个 Hacker News 上的项目**，首批付费用户的主要来源依次是：口碑（40）、应用商店 / 插件市场（33）、SEO（27）、社区帖子（20）、直接外联（15）、Product Hunt（8）。Product Hunt 多作为辅助渠道出现：给信任背书，不是稳定的客户来源
- **2026 年 5 月 5 个 Product Hunt 发布的复盘**：7 天注册数相差 6.3 倍（71 到约 450），差距主要来自创始人本来就有的受众，而不是 Product Hunt 本身
- **Hacker News 首页**：多数案例在 1–3 万访客，几乎全在 24–48 小时内，之后迅速归零。Show HN 帖子常常只有几百到几千
- **Stripe Atlas**：20% 的公司在 30 天内拿到第一个付费客户，2020 年是 8%

### 6. B2B 的渠道结构会随规模迁移

- **High Alpha 2025 SaaS Benchmarks**（接替 OpenView）：外联在早期影响大，规模越大影响越小；5,000 万美元 ARR 以上的公司，约 60% 的新增 ARR 来自老客户
- 多家机构的经验估算（不是严谨调查，数字分歧很大）一致的方向是：**创始人外联最先 → 内容 / 自然流量逐渐超过外联 → 付费更晚 → 合作、活动、老客户扩张在规模化以后变重要**
- Lenny 调研 25 位投资人：早期月增长率意义不大，因为基数太小；100 万美元 ARR 以下，一般好的月增长在 15%–25%。B2B 更看从正式上线到 100 万 ARR 用了多久，一年内算好，9 个月算很好

### 7. 你看到的归因是偏的

Refine Labs 跟踪了 620 个转化：软件归因说 78% 来自搜索（直接访问 + 自然搜索），用户自己说只有 12%；用户说 85% 来自暗社交（社媒、播客、口碑、社区）。这份研究由一家推销「需求创造」的机构做，数字偏向它的结论，但方向和很多人的经验一致：**口碑、KOL、社区带来的人，常常是记住名字后去 Google 搜，于是被记成「自然搜索」或「直接访问」。**

**对公式的含义：** 光看 GA4 去估权重，会高估 SEO 和直接访问，低估口碑、KOL 和社区。必须加上「你从哪知道我们的」自述归因。

## 二、公式

### 1. 总式

把 Bass 模型的两项拆开，外部推力换成各个渠道之和：

```text
新增(t) = [ Σc  wc(s) · ec(t) · gc( Xc(t) )  +  q · A(t) ]  ×  (1 − N(t)/M)
          └──────── 外部推力：各个渠道 ────────┘   └ 内生拉力 ┘   └ 市场余量 ┘
```

| 符号 | 意思 |
| --- | --- |
| c | 渠道：SEO、社区、KOL、发布、外联、广告…… |
| s | 阶段：冷启动 / 1→10 / 10→100 |
| wc(s) | 渠道 c 在阶段 s 的权重，主要由产品形态和受众决定 |
| ec(t) | 渠道 c 的当期效率，随日历时间衰减（规律 2） |
| Xc(t) | 你在这个渠道上的累积投入，带滞后和残留 |
| gc(·) | 投入到产出的响应曲线，会饱和 |
| A(t) | 活跃用户数，= Σ 每期新增 × 留存曲线 |
| q | 口碑系数：每个活跃用户每期带来多少新人 |
| M | 细分市场上限 |

和 Bass 原式的区别是：口碑项乘的是**活跃用户 A**，不是累计用户 N。留不住的人不会帮你传。所以留存是口碑的前提，这也是为什么 PMF 没过之前，砸渠道只是在往漏桶里倒水。

### 2. 渠道的四种时间形状

不同渠道对投入的响应在时间上的形状完全不同，这决定了它们在哪个阶段权重高。

| 形状 | 代表渠道 | 投入停了以后 | 响应函数 | 适合的阶段 |
| --- | --- | --- | --- | --- |
| 脉冲型 | Product Hunt、Show HN、媒体报道、KOL 单次推荐 | 1–3 天归零 | 衰减很快的 adstock，λ ≈ 0.1–0.3 | 冷启动：拿第一批人和反馈 |
| 线性型 | 冷外联、付费广告、Newsletter 赞助 | 立刻停 | 当期投入过 Hill 饱和曲线 | 外联在冷启动；广告在 10→100 |
| 累积型 | SEO、YouTube、目录站外链、Reddit 老帖、开源仓库 | 继续产出，慢慢衰减 | 产出取决于累积存量，起效有几个月滞后 | 1→10 开始接手 |
| 复利型 | 口碑、产品内分享、邀请、UGC、集成 | 由用户自己维持 | 和活跃用户数成正比 | 1→10 以后越来越重 |

这几个函数借用营销组合建模（MMM）的标准写法：

```text
残留（adstock）： X'(t) = x(t) + λ · X'(t−1)        λ 越大，效果拖得越久
饱和（Hill）：    g(X) = Xᵃ ÷ (Xᵃ + Kᵃ)             K 是半饱和点，a 决定曲线陡不陡
滞后：           产出(t) 取 X'(t − L)                SEO 的 L 以月计，广告的 L ≈ 0
```

Meta 的 Robyn 和 Google 的 Meridian 两个开源 MMM 工具都用这两种变换。

### 3. 病毒项的细节

如果产品本身有邀请或分享机制，口碑项可以展开成 David Skok 的病毒公式：

```text
K = 每个新用户发出的邀请数 × 邀请转化率
用户(t) = 用户(0) × ( K^(t/ct + 1) − 1 ) ÷ ( K − 1 )      ct：一轮邀请的周期
```

Skok 的结论：因为 K 是 t/ct 次方，**缩短周期 ct 比提高 K 有效得多**。他的例子里，同样 K = 2，周期从 2 天缩到 1 天，20 天后的用户从约 2 万变成 2,000 万。K 小于 1 时不会自己爆发，但依然能放大其他渠道的效果：每个外部来的用户，最终会变成 1 ÷ (1 − K) 个用户。

### 4. 渠道-模式匹配：哪些渠道根本进不了公式

Balfour 的「四个匹配」里有一条是渠道和收费模式的匹配：客单价决定了你能用得起哪些渠道。他在 HubSpot 做 Sidekick 时，每月 25 美元的价格用不起高成本渠道，又在低成本渠道上拿不到足够的人，最后把 25 美元档去掉，改成 50 美元。

写进公式就是一个约束：

```text
如果  渠道 c 的获客成本 CACc  >  LTV ÷ 3，那么 wc = 0
```

所以「我们的阶段权重表」不能直接照搬别人的：每月 5 美元的 C 端工具，冷外联和销售的权重恒为零；年费上万的 B2B，Product Hunt 的权重接近零。

### 5. 一个能跑的最小模拟

下面的脚本按上面的公式，模拟一个工具站两年里每周的新增和来源构成。参数全是假设，用来看形状、调参，不是预测。

```python
import math

WEEKS = 104
M = 50_000            # 这个细分市场里潜在用户的上限
q = 0.38 / 52         # 口碑系数（Bass 平均值换算到周）
retention = 0.35      # 新用户里长期留下来的比例，只有留下来的人会带人

def adstock(xs, lam):
    out, carry = [], 0.0
    for x in xs:
        carry = x + lam * carry
        out.append(carry)
    return out

def hill(x, k, a=1.5):
    return x**a / (x**a + k**a) if x > 0 else 0.0

# 每个渠道每周的投入（小时或美元，自己定单位）
launch = [40 if w in (2, 30) else 0 for w in range(WEEKS)]          # 两次发布
outreach = [10 if w < 26 else 2 for w in range(WEEKS)]              # 前半年手动外联
seo_pages = [5 if w >= 4 else 0 for w in range(WEEKS)]              # 每周 5 篇
seo_stock = [sum(seo_pages[:w + 1]) for w in range(WEEKS)]          # 累积页面数
ads = [0 if w < 52 else 300 for w in range(WEEKS)]                  # 第二年开始投广告

channels = {
    #        每周响应                                               最大周新增
    "launch":   (adstock(launch, 0.2),   lambda x: hill(x, 30),   400),
    "outreach": (adstock(outreach, 0.5), lambda x: hill(x, 15),    60),
    "seo":      (seo_stock,              lambda x: hill(x, 400, 2.0), 900),
    "ads":      (adstock(ads, 0.4),      lambda x: hill(x, 600),   250),
}

N = 0.0
rows = []
for w in range(WEEKS):
    room = max(M - N, 0) / M
    by_src = {c: cap * f(xs[max(w - (8 if c == "seo" else 0), 0)]) * room
              for c, (xs, f, cap) in channels.items()}
    by_src["wom"] = q * (N * retention / M) * (M - N)
    new = sum(by_src.values())
    N += new
    rows.append((w, N, new, by_src))

for w in (3, 12, 26, 52, 78, 103):
    _, n, new, s = rows[w]
    share = " ".join(f"{k}={v / new:.0%}" for k, v in s.items())
    print(f"week {w + 1:>3}  累计 {n:>7.0f}  本周新增 {new:>5.0f}  {share}")
```

输出（口碑弱：q = 0.38/年，留存 35%）：

```text
week   4  累计     411  本周新增    84  launch=57% outreach=42% seo=0% ads=0% wom=1%
week  13  累计     751  本周新增    38  launch=0% outreach=95% seo=0% ads=0% wom=5%
week  27  累计    1442  本周新增    57  launch=0% outreach=42% seo=52% ads=0% wom=6%
week  53  累计    4710  本周新增   247  launch=0% outreach=3% seo=69% ads=24% wom=4%
week  79  累计   13651  本周新增   382  launch=0% outreach=1% seo=71% ads=21% wom=7%
week 104  累计   23260  本周新增   372  launch=0% outreach=1% seo=75% ads=16% wom=9%
```

把 q 改成 1.5/年、留存改成 50%（口碑强）：

```text
week   4  累计     415  本周新增    88  launch=55% outreach=40% seo=0% ads=0% wom=5%
week  13  累计     819  本周新增    47  launch=0% outreach=76% seo=0% ads=0% wom=23%
week  27  累计    1704  本周新增    76  launch=0% outreach=32% seo=39% ads=0% wom=30%
week  53  累计    5934  本周新增   303  launch=0% outreach=2% seo=55% ads=19% wom=24%
week  79  累计   17066  本周新增   485  launch=0% outreach=1% seo=51% ads=15% wom=33%
week 104  累计   29020  本周新增   446  launch=0% outreach=1% seo=49% ads=10% wom=40%
```

能看出几件事：

- 前 3 个月，发布和外联是全部来源；SEO 是零，因为页面还没积累、还在滞后期
- 第 13 周发布的脉冲已经散了，如果这时候外联也停了，新增会掉到接近零。这就是很多新站「发布完就死」的样子
- 半年后 SEO 接手，成为最大来源
- 口碑能不能成为主力，取决于 q × 留存。同样的渠道投入，口碑强的版本两年后多了 25% 的用户，而且来源更分散，不怕某个渠道衰减

这个脚本以后放进 `../craftsail` 时，要加上：渠道效率随日历时间衰减（ec）、留存曲线而不是一个常数、每个渠道的转化率，以及用真实数据拟合参数（第五节）。

## 三、自变量清单

下面是一个出海工具站 / 内容站可能用到的全部自变量。「形状」见上一节。见效时间和持续时间是经验区间，要用自己的数据校准。

| # | 自变量 | 形状 | 见效 | 持续 | 主要依据 | 不适合 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 创始人人脉和手动拉人 | 线性 | 立刻 | 停了就没 | Lenny B2B 前 10 客户第一来源；PG《Do Things That Don't Scale》 | 没有目标人群人脉的 C 端产品 |
| 2 | 冷外联（邮件、私信） | 线性 | 1–2 周 | 停了就没 | Lenny B2B 第二来源 | 低客单 C 端 |
| 3 | 社区（Reddit、HN、Discord、论坛、Slack 群） | 脉冲 + 累积 | 1 天 | Reddit 老帖长尾 | IndieLaunches 第 4 来源；Lenny 前 1,000 用户 | 没时间先当成员的 |
| 4 | 发布平台（Product Hunt、Show HN、BetaList） | 脉冲 | 1 天 | 2–3 天 | HN 首页 1–3 万访客；PH 多为辅助渠道 | 已经发布过的 |
| 5 | 目录站 / 导航站 / awesome 列表 | 累积 | 立刻 | 外链长期 | AI 目录带来的引荐 + 外链 | — |
| 6 | SEO（手写内容） | 累积 | 3–12 个月 | 长期 | MicroConf 影响最大的两项之一；Ahrefs 新页进前十的比例 | 需求没有搜索词的 |
| 7 | 程序化 SEO / 免费小工具（工程即营销） | 累积 | 3–6 个月 | 长期 | 《Traction》工程即营销；规模化内容滥用的风险 | 每页拿不出独有内容的 |
| 8 | AI 推荐（GEO） | 累积 | 1–3 个月 | 长期 | AI 来源约占网站流量 1% 左右但转化高；ChatGPT 结果和 Bing 索引高度相关 | — |
| 9 | 社媒内容 / Build in public（X、LinkedIn、Threads 等） | 累积 | 慢 | 长期 | 粉丝数和收入相关性弱（TrustMRR） | 不愿意持续 6 个月以上的 |
| 10 | 视频（YouTube、TikTok、Shorts） | 累积 | 慢 | 视频会被搜索收录 | 测评类视频长尾 12–24 个月（行业说法） | 操作很简单、没东西演示的 |
| 11 | KOL / 创作者合作（YouTube、X、Newsletter 赞助） | 脉冲 + 累积 | 立刻 | 测评视频长尾 | 开发者频道 CPM 高；小 KOL 互动率高（多为厂商数据） | 还没有 PMF 的 |
| 12 | PR / 媒体 | 脉冲 | 立刻 | 外链长期 | Lenny：偶尔有用，多数没用 | 冷启动 |
| 13 | 插件市场 / 应用商店（Chrome、VS Code、Figma、Shopify） | 累积 | 1–3 个月 | 长期 | IndieLaunches 第 2 来源 | 不依附平台的产品 |
| 14 | 集成和合作（BD、联合发布、模板市场） | 累积 | 慢 | 长期 | Reforge 销售 / 合作环 | 冷启动没人愿意合作 |
| 15 | 开源（GitHub） | 累积 | 慢 | 长期 | 开发者工具常见主渠道 | 非开发者产品 |
| 16 | 自有受众（邮件列表、Newsletter、RSS） | 复利 | 慢 | 长期 | 每次发布都能复用 | — |
| 17 | 口碑和推荐 | 复利 | 等用户够多 | 长期 | MicroConf、IndieLaunches 的第一来源；Bass q 项 | PMF 没过的 |
| 18 | 产品内传播（Made with、分享链接、邀请） | 复利 | 等用户够多 | 长期 | Skok 病毒公式 | 用户产出物不对外的 |
| 19 | 联盟营销（Affiliate） | 线性 | 慢 | 长期 | 按成交付费 | 没收入、客单低的 |
| 20 | 付费广告（Google、Meta、Reddit、X） | 线性 | 立刻 | 停了就没 | MicroConf：57% 回本超 7 个月或说不清 | LTV 没算清之前 |
| 21 | 线下活动、演讲、会议 | 脉冲 | 立刻 | 人脉长期 | High Alpha：各 ARR 段都认为最有效（B2B） | 海外 C 端小工具 |

还有几个不是渠道、但会乘在所有渠道上的变量：

| 乘数 | 作用在哪 | 为什么 |
| --- | --- | --- |
| 定位清晰度 | 所有外部渠道的转化率 | 一句话说不清，所有渠道的转化都低；AI 也对不上你 |
| 激活率 | 所有渠道的「到站 → 用户」 | 来了没用上，等于没来 |
| 留存 | 口碑项 q · A(t) | 留不住就没有口碑，Bass 的 q 项失效 |
| 品牌认知 | 品牌词搜索、直接访问、AI 提及 | 很多渠道的效果最后是以品牌搜索的形式出现的 |

## 四、阶段和权重

### 1. 阶段怎么分

用结果分，不用时间分：

| 阶段 | 一句话 | 进入下一阶段的标志 | 对应 [工具产品出海运营](工具产品出海运营.md) |
| --- | --- | --- | --- |
| S0 冷启动（0 → 1） | 找到第一批真用户 | 有 100 个左右活跃用户，留存曲线开始走平 | 阶段 0 验证 |
| S1 1 → 10 | 找到第一条能重复的渠道 | 有一个渠道每周稳定来人，且投入加倍时产出接近加倍 | 阶段 1 找渠道、阶段 2 找付费 |
| S2 10 → 100 | 放大，接第二、第三个增长环 | 主渠道开始饱和或衰减，第二渠道撑得起 30% 以上 | 阶段 3 放大 |

下面这张表是根据第一节的依据整理出来的**先验判断**，不是测出来的值。★ 越多，在该阶段越可能是主力。面向海外 C 端 / 小团队工具站，客单价不高。

| 自变量 | S0 冷启动 | S1 1→10 | S2 10→100 | 依据 |
| --- | --- | --- | --- | --- |
| 创始人人脉和手动拉人 | ★★★★★ | ★★ | ★ | 不能规模化；Lenny 两组调研 |
| 社区 | ★★★★ | ★★★ | ★★ | 早期最直接的「去用户在的地方」 |

看这张表的方法：

- **每一列只挑 1–2 个主力。** 规律 1 说的是幂律，不是平均分配
- **S0 的主力全是创始人的时间**，不是钱
- **S1 是交接期**：脉冲型渠道的权重在掉，累积型和复利型在涨。这一阶段最危险，脉冲散了、累积还没起来，中间会有一段低谷（模拟里第 13 周的样子）。所以 S0 就要开始写 SEO 内容，哪怕当时权重很低
- **S2 的问题是饱和和衰减**：主渠道会撞上 Hill 曲线的平台期，也会被竞争对手抄。要提前准备下一个环（Casey Winters：所有渠道最终都会趋于平缓，要按顺序接上新的增长环来维持 S 曲线）

## 五、用自己的数据估权重

先验只是起点。不同阶段数据量不同，能用的方法也不同。

### 1. 每周记一张表

每个渠道一行，每周一列。至少要有：

| 字段 | 说明 |
| --- | --- |
| 投入：小时 | 这周在这个渠道花了多少时间 |
| 投入：钱 | 广告、赞助、工具 |
| 投入：件数 | 发了几篇、几个帖子、几封邮件 |
| 到站 | UTM 归因的会话（见 [工具产品看数据](工具产品看数据.md)） |
| 自述归因 | 注册时问「你从哪知道我们的」，用自由文本，不用下拉框 |
| 新增用户 / 激活用户 | 按渠道拆 |
| 备注 | 发布、算法更新、节假日 |

自述归因一定要加。规律 7 说过，只看软件归因会高估搜索和直接访问。

### 2. S0：数太小，不建模，比效率

一周十几个用户，回归没有意义。比的是每小时投入换来多少激活用户：

```text
渠道效率c = 激活用户c ÷ 投入小时c
```

每个渠道按 [工具产品出海运营](工具产品出海运营.md) 第十一节的实验卡去测，2–4 周一轮。目标不是估准权重，是找到那个明显比其他渠道高一个数量级的渠道。

### 3. S1：简单回归，开始估残留和滞后

有了 20–30 周的数据以后，可以拟合一个小模型：

```text
周新增(t) = Σc βc · adstock(xc, λc)(t − Lc)  +  q · A(t)  +  ε
```

- 渠道合并成 3–5 组（比如：社区与发布、内容与 SEO、KOL、口碑），不然参数比数据点还多
- λ 和 L 先用经验值固定（脉冲型 λ ≈ 0.2，SEO 的 L 取 8–12 周），只估 β
- 每组至少要有投入有变化的几周，一直不变的渠道估不出效果

### 4. S2：MMM 和增量实验

规模起来以后，可以用 Robyn 或 Meridian 做正式的营销组合建模。门槛要心里有数：

- Google 建议 Meridian 至少 2 年周数据（分地区模型）或 3 年（全国模型）
- 每个参数最好有 10–15 个数据点，4 个算样本很小。渠道太多就合并
- 小广告主的投入常常到不了饱和区，饱和曲线基本估不出来
- 最好配一次增量实验校准：按地区或时间停掉某个渠道，看新增掉多少

在这之前，用贝叶斯先验（比如 λ 在 0.3–0.8 之间）可以在数据少的时候稳住模型。

### 5. 衰减要单独看

同一个渠道，每个季度算一次「单位投入的产出」。如果在投入不变的情况下连续两个季度下降，就是 ec(t) 在衰减（规律 2），这时要开始找下一个渠道，而不是加大投入。

## 七、证据的可信度

这篇里的数字来源质量差别很大，引用时要分清：

| 等级 | 来源 | 本文例子 |
| --- | --- | --- |
| A | 同行评审、官方文档 | Bass 模型、Sultan 等 1990 元分析、Google Meridian 文档 |
| B | 大样本行业数据，方法公开 | Ahrefs 排名时间研究、MicroConf 约 700 家调查、High Alpha Benchmarks、Lenny 的系统调研 |
| C | 个案、厂商和机构博客 | HN 流量复盘、Product Hunt 五个发布、Refine Labs、KOL 回报率、各种「按 ARR 阶段的渠道占比」 |
