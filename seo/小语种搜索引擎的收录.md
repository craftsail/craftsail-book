# 小语种搜索引擎的收录

GSC 和 Bing Webmaster Tools 接好以后，常有人问：还要不要去 Yandex、Naver 这些地方提交一遍？

答案取决于网站用什么语言、面向哪个国家，而不是接的引擎越多越好。纯英文站有 Google + Bing + IndexNow，基本就覆盖全了。做多语言站时，每加一种语言，就去看一下那个国家的主力搜索引擎是不是 Google，不是的话再单独接。

这篇按语言讲哪些要接、怎么接、接完看什么。不含中国大陆的搜索引擎。份额数据来自 StatCounter 2026 年 9 月，所有设备。

---

## 一、先按语言看要不要接

| 语言 / 市场 | Google | 其他有份额的引擎 | 要另外接什么 |
| --- | --- | --- | --- |
| 德语（德国） | 87.84% | Bing 6.49%、Yahoo 1.71%、Yandex 1.56%、DuckDuckGo 1.07%、Ecosia 1.03% | 不用。Qwantbot 别挡 |
| 法语（法国） | 88.16% | Bing 5.47%、Yahoo 2.75%、Ecosia 1.34%、Qwant 0.86%、DuckDuckGo 0.84% | 不用。Qwantbot 别挡 |
| 西班牙语（西班牙） | 93.81% | Bing 3.49%、Yahoo 1.92% | 不用 |
| 西班牙语（墨西哥） | 88.08% | Bing 9.43%、Yahoo 1.78% | 不用 |
| 葡萄牙语（巴西） | 88.41% | Bing 9.63%、Yahoo 1.54% | 不用 |
| 葡萄牙语（葡萄牙） | 87.34% | Bing 10.18% | 不用 |
| 日语 | 59.27% | Bing 31.41%、Yahoo 7.61% | 不用。Yahoo Japan 的网页结果来自 Google |
| 韩语 | 47.97% | **Naver 43.06%**、Bing 4.83%、Daum 0.73% | **Naver**，Daum 可选 |
| 俄语（俄罗斯） | 28.12% | **Yandex 70.33%** | **Yandex** |
| 土耳其语 | 73.42% | **Yandex 25.19%** | **Yandex** |

几点说明：

- 日本的 Bing 31% 和 [Bing 的收录](Bing的收录.md) 里提到的 9 月全球跳涨是同一个现象，StatCounter 可能会修正，先别当真。日本市场管好 GSC 和 Bing 就够了
- 表里「不用」的意思是不用接新的后台。Bing 的份额在西语、葡语市场接近 10%，所以 Bing Webmaster Tools 一定要接
- 判断某个语言要不要单独接，看两点：当地第二名是不是自己有索引（Yahoo、DuckDuckGo 用的是 Bing 的结果，不算），份额有没有超过 5%

## 二、德语、法语、西语、葡语：做好 Google 和 Bing

这几种语言的流量几乎都来自 Google 和 Bing，要做的事在 [GSC 与 Bing 的接入操作](GSC与Bing的接入操作.md) 里都讲过了。多语言站额外要注意的是：

- **每种语言用独立的 URL**，比如 `/de/`、`/fr/`，不要用 Cookie 或浏览器语言切换同一个 URL 的内容
- **hreflang 写全**：每个语言版本都列出所有语言版本，包括自己，再加一个 `x-default`。Google 和 Yandex 都读 hreflang
- **sitemap 里每种语言的 URL 都要有**，提交到 GSC 和 Bing 各一次
- **西语、葡语分清地区**：面向墨西哥和西班牙用 `es-MX` / `es-ES`，面向巴西和葡萄牙用 `pt-BR` / `pt-PT`，内容差别不大就只用 `es` / `pt`

### 法国和德国的欧洲索引

Ecosia 和 Qwant 一起成立了 European Search Perspective（EUSP），自建的索引叫 Staan。2025 年起法国、2026 年 7 月起德国的搜索结果逐步换成 Staan，其余地区还部分用 Bing。

Staan 目前**没有站长后台**，也不在 IndexNow 名单里，靠 Qwant 的爬虫自己抓。能做的只有一件事：robots.txt 别挡 `Qwantbot`。它有好几个变体（`Qwantbot`、`Qwantbot-news` 等），一条 `User-agent: Qwantbot` 规则都能匹配到。份额加起来 2% 左右，不用专门优化，保证能被抓到就行。

## 三、Yandex：俄语、土耳其语、哈萨克斯坦

Yandex 在俄罗斯占七成，在土耳其和哈萨克斯坦占四分之一以上。做这几个市场一定要接。

### 1. 账号

- 先注册一个 Yandex ID。**需要手机号**，用来登录和找回账号，不接受 VoIP 号码。用一个能长期收短信的号码，临时号码以后可能登不上
- 2024 年 7 月，Yandex 的俄罗斯业务已经卖给了俄罗斯投资人财团。Webmaster 是免费工具，没有查到它被制裁限制的官方说法；Yandex 的广告和支付受制裁影响比较大。公司业务敏感的话，先问一下合规

### 2. 验证和提交

1. 打开 [webmaster.yandex.com](https://webmaster.yandex.com)，点「Add site」，填首页 URL
2. 选一种验证方式：HTML 文件、`<head>` 里的 meta 标签、DNS TXT 记录。验证完不要删掉，Yandex 会定期复查
3. 「Indexing → Sitemap files」提交 sitemap。官方说新 sitemap 一般**两周左右**处理完
4. 「Indexing → Reindex pages」手动提交重要页面。每天有配额，主域名和所有子域名共用，具体数字以后台显示为准（第三方指南写的是每天 150 个）。官方说提交后 7–14 天更新
5. 部署时自动推 IndexNow，推给 Bing 时 Yandex 也会收到，见第七节

### 3. 后台看什么

| 报告 | 看什么 |
| --- | --- |
| Indexing → Searchable pages | 哪些页面在搜索结果里、哪些被排除和排除原因，最多列 5 万条 |
| Indexing → Important pages | 最多 100 个页面，收录状态变化会发通知。把首页和核心页加进去 |
| Diagnostics | 站点级别的问题，比如 robots.txt 挡住、证书错误、大量 404 |
| Search queries | 展示、点击、排名，相当于 GSC 的效果报告 |
| Regionality | 面向特定国家或城市的站在这里设地区 |

Yandex 对重复内容比 Google 敏感，`www` 和非 `www`、`http` 和 `https` 一定要 301 到同一个地址，canonical 写清楚。

## 四、Naver：韩语

韩国是 Google 和 Naver 各占一半左右。Naver 的爬虫叫 **Yeti**，有自己的索引，不会自动发现你的站，GSC 收录了也不等于 Naver 收录。

### 1. 账号

- 注册 Naver 账号，登录 [searchadvisor.naver.com](https://searchadvisor.naver.com)
- 后台**只有韩文**。基础的站点工具不需要韩国手机号，Naver Blog 这类功能可能要

### 2. 验证和提交

1. 顶部「웹마스터 도구」→「사이트 등록」，填网址
2. 验证：上传 HTML 文件到根目录，或者在 `<head>` 里加 `naver-site-verification` meta 标签。**验证有效期一年**，文件或标签一直留着才会自动续期
3. 「요청 → 사이트맵 제출」提交 sitemap
4. 「요청 → RSS 제출」**再交一个 RSS 或 Atom feed**。Naver 两个都用，只交 sitemap 是常见的漏项。feed 里放最新的文章，最好带全文
5. 「요청 → 웹 페이지 수집」手动请求抓取核心页面，每天有配额
6. 部署时推 IndexNow，Naver 在名单里

多语言站可以单独给 Yeti 准备一份只含韩语 canonical URL 的 sitemap，每条带 `lastmod`，比让它从 hreflang 里自己找更省事。

### 3. 查收录

Search Advisor 的报告比 GSC 简单。最直接的办法是在 Naver 里搜 `site:yourdomain.com`。

### 4. Daum

Daum 的份额已经不到 1%。想顺手接的话，到 [webmaster.daum.net](https://webmaster.daum.net) 申请一个 PIN 码，按页面提示把它加到 robots.txt 里完成验证。不需要 Daum 账号，也没有提交 sitemap 的地方。

## 五、Seznam：捷克语

Seznam 在捷克占 15% 左右，爬虫叫 **SeznamBot**，有自己的索引。只做捷克语内容时才需要接。

1. 用 Seznam 账号登录站长后台。地址有好几个说法，最近几个项目实际用的是 [reporter.seznam.cz/wm](https://reporter.seznam.cz/wm)
2. 验证：在 `<head>` 里加 `<meta name="seznam-wmt" content="...">`，或者在根目录放一个 `seznam-wmt-<token>.txt` 文件（内容只有 token，不要末尾换行）。有人 meta 标签一直验证不过，换成文件就好了。Seznam 会定期复查，别删
3. sitemap 写进 robots.txt 的 `Sitemap:` 行
4. 新页面推 IndexNow，Seznam 在名单里。也可以在 [search.seznam.cz/pridej-stranku](https://search.seznam.cz/pridej-stranku) 手动提交单个 URL

社区经验：SeznamBot 抓 `.cz` 域名比抓国际域名积极，sitemap 的作用不明显，外链和 IndexNow 更管用。

---

## 六、Cốc Cốc：越南语

Cốc Cốc 在越南占 6% 左右，有自己的索引和 Search Console，可以提交 sitemap 和单个 URL。入口在 [coccoc.com/search/console](https://coccoc.com/search/console/get-your-website-on-coc-coc-search)，旧的 `help.coccoc.com` 地址可能已经失效。

- 先在 Cốc Cốc 里搜 `site:yourdomain.com yourdomain.com`，看有没有被收录
- 不在 IndexNow 名单里，要手动提交
- 越南语内容要同时照顾带声调和不带声调的写法，很多用户搜索时不打声调

份额小，做越南语站时花十分钟提交一下就行。

---

## 七、IndexNow：推一次，几家都收到

截至 2026 年 10 月，[IndexNow 的参与名单](https://www.indexnow.org/searchengines.json) 是：

| 参与方 | 对应市场 |
| --- | --- |
| Bing | 全球，也覆盖 Yahoo、DuckDuckGo、Copilot |
| Yandex | 俄罗斯、土耳其、哈萨克斯坦 |
| Naver | 韩国 |
| Seznam | 捷克 |
| Yep | Ahrefs 的搜索引擎 |
| Internet Archive | 网页存档 |
| Amazonbot | Amazon（Alexa、Rufus 等） |

推给任意一家，其他参与者都会收到，所以不用每家各推一次。接法和 curl 示例见 [Bing 的收录](Bing的收录.md)。

**Google、Qwant / Staan、Cốc Cốc、Daum 不在名单里。**

---

## 八、robots.txt：别挡住各家的爬虫

没有后台的引擎只能靠自己抓，有后台的也要先抓得到。上线前检查一遍 robots.txt 有没有误伤：

| 引擎 | User-agent |
| --- | --- |
| Yandex | `YandexBot` |
| Naver | `Yeti` |
| Daum | `Daum` |
| Seznam | `SeznamBot` |
| Qwant / Staan | `Qwantbot` |
| Cốc Cốc | `coccocbot-web` |

最常见的问题是为了挡 AI 爬虫或者采集器，写了一条「只允许 Googlebot 和 Bingbot，其他全部 Disallow」的白名单，结果把上面这些一起挡掉了。用白名单的话，要把目标市场的爬虫都加进去。

另外，有些 CDN 和 WAF 的「机器人防护」会拦不认识的爬虫，返回 403 或验证码。在 Cloudflare 的安全事件里搜一下这些 User-agent，看有没有被拦。

## 九、上线清单

**加一种新语言时**

- [ ] 查一下这个国家的搜索引擎份额，对照第一节的表
- [ ] 新语言的 URL 加进 sitemap，hreflang 两边都写上
- [ ] robots.txt 和 WAF 没挡住当地的爬虫

**按语言接后台**

- [ ] 俄语、土耳其语、哈萨克斯坦：Yandex Webmaster，验证、提交 sitemap、把核心页加进 Important pages
- [ ] 韩语：Naver Search Advisor，验证、提交 sitemap 和 RSS、请求抓取核心页；Daum 可选
- [ ] 捷克语：Seznam Webmaster，验证，sitemap 写进 robots.txt
- [ ] 越南语：Cốc Cốc Search Console 提交 sitemap
- [ ] 部署流水线里的 IndexNow 推送覆盖新语言的 URL

**之后**

- 每月看一次各家后台的收录数和排除原因，和 GSC 里同一语言的收录数对比，差很多就去查
- 在 GA4 里按来源看 `yandex`、`naver`、`seznam`、`coccoc` 的会话。某一家长期没流量，保持收录就行，不用为它改内容
